# Features

전체 제품 범위는 [PRD.md](../PRD.md) 참고. 이 문서는 그중 MindProfiler(iOS)에서 **현재 구현된 것**과
**아직 안 된 것**을 구분해서 추적한다.

## 구현됨

### 로그인 (`Views/Login`)
- Google Sign-In(`GoogleSignIn` SDK) → 백엔드 `POST /auth/google`로 idToken 교환 → JWT를 Keychain에 저장.

### 진입 화면 / 홈 (`Views/Home`)
- Pixabay 랜덤 고양이 사진 + 랜덤 위로 문구. 홈 탭에 들어올 때마다(`onAppear`) 새로 랜덤 사진을 가져온다
  (앱 세션당 한 번만 가져오지 않음).
- Pixabay 요청이 실패하면(네트워크 오류 등) 빈 화면/스켈레톤 대신 `Assets.xcassets`에 번들로 넣어둔
  고정 사진(`FallbackCatPhoto`)을 보여준다.
- 그 외 PRD의 기분/커피 간편 입력, 복용약 퀵버튼은 **아직 홈 화면엔 없음** (기분/커피는 통계에서만 조회 가능,
  입력 폼은 캘린더 쪽에 있음).

### 달력보기 (`Views/Calendar`)
- 월 달력 그리드, 날짜 탭 → bottom sheet로 유형 선택 후 입력.
- 구현된 유형: 검사(HRV, `ExamEntryForm`) / 커피(`CoffeeEntryForm`) / 기분(`MoodEntryForm`).
- PRD에 있는 운동/약복용/이벤트 유형은 **폼 미구현**.

### 나의 Trend / 통계 (`Views/Statistics`)
- 기분·커피 막대그래프만 구현. PRD의 "나의 Trend"(HRV/웨어러블 통합 대시보드)는 대부분
  [오늘의 패턴](#오늘의-패턴-viewshrvanalysis)이 흡수함.

### 오늘의 패턴 (`Views/HRVAnalysis`)

라인 차트(HRV)와 Gantt 차트(수면/운동)를 별도 `Chart`로 분리해서 세로로 쌓아 보여준다. 두 차트는
x축 눈금 위치를 동일한 배열로 공유해서 정렬을 맞춘다 (월별 모드는 Gantt 차트 없이 라인 차트만).

- 시간별/일별/월별 3가지 보기 단위를 세그먼트 피커로 전환.
  - 시간별: 애플워치가 기록한 HRV 원시값을 그대로 시간축에 표시.
  - 일별: 해당 일 HRV 값들의 중앙값 하나로 표시.
  - 월별: 해당 월 HRV의 최소~최대를 막대 높이로, 중앙값을 같은 너비의 굵은 선으로 표시.
- HRV 라인 위에 검사(병원) 시점의 SDNN을 세모 마커로 오버레이.
- 워치를 착용하지 않은 구간은 선이 끊어짐 (gap 임계값: 시간별 3시간, 일별 1.5일).
- 수면/운동은 Gantt 레인에 색으로 구분해 표시.
- 가로 드래그로 스크롤, 현재 시각 이후로는 스크롤 불가.
- y축은 0부터 시작하고 50 단위 고정 그리드 (모든 모드 공통, 월별 포함), 라벨은 레이아웃 공간을
  차지하지 않고 차트 위에 고정된 위치로 떠 있다 (`chartYAxis(.hidden)` + `chartOverlay`로 직접 그림).
- 차트 높이는 화면 전체 높이의 40%(라인/월별 차트), Gantt 차트는 주 차트의 35%(절반의 70%).
- 범례는 각 색이 무엇을 뜻하는지 보여주고, 항목을 탭하면 차트에서 보이기/숨기기를 토글한다
  (숨긴 항목은 옅게 표시).
- **HRV 이상치 강조**: 최근 30일 HRV 중앙값의 25% 미만인 값은 빨강 점으로 강조 표시. 최근 30일
  중앙값 자체는 회색 점선으로 표시. 둘 다 범례에서 토글 가능.
- **수면 부족 강조**: 수면이 5시간 미만이면 Gantt 막대를 빨강으로 강조하고, 막대 위에 수면 시간 텍스트 표시.
  중간에 1시간 이하로 깬 구간은 별도 수면으로 나누지 않고 하나의 연속된 수면으로 합쳐서 계산한다
  (안 그러면 자다가 잠깐 깬 것만으로도 두 구간 다 "5시간 미만"으로 잘못 강조됨).
- **값 툴팁**: 라인 차트를 드래그하면 가장 가까운 데이터 포인트의 날짜·값을 제목 아래에 보여준다
  (간트/월별 차트에는 적용 안 됨 — 월별은 "값 하나"가 아니라 최소/최대/중앙값 범위라 같은 형식이 안 맞음).
- **x축 라벨 겹침 생략**: 인접한 라벨의 픽셀 간격이 10px 미만이면 뒤쪽 라벨은 생략한다(그리드 선은 유지).

## 설계 목표 (설계는 됐지만 아직 코드에 없음)

"오늘의 패턴" 화면에 대해 다음은 디자인/스펙으로는 정해졌지만 아직 구현되지 않았다:

- **Gantt 레인 확장**: 구글 캘린더 일정을 같은 레인에 겹쳐서 표시하고, 탭/오버 시 제목·시간·장소·참석자
  툴팁 표시. 이벤트(유형별 아이콘)·커피(컵 아이콘, 하루 2잔↑ 빨강)·기분(하트, 점수별 색)도 Gantt 위에 오버레이.
  구글 캘린더 연동 자체가 없어서 막혀 있음 (아래 "아직 없음" 참고).

## 아직 없음 (PRD 대비 미구현)

- **복용약 관리** 화면 및 아침/취침 퀵버튼 (`/medicine` 대응 화면 없음).
- **이벤트 기록** (약 변경/대인관계/업무 스트레스/병원 진료/기타).
- **운동 기록 입력 폼** (HealthKit에서 읽어오는 것과 별개로, 캘린더에서 수동 입력하는 기능).
- **구글 캘린더 연동** (읽기 전용 일정 조회 자체가 없음 — 위 "Gantt 레인 확장"의 전제 조건).
- `Views/Settings/SettingsView.swift`는 초기 스캐폴딩 이후 `RootTabView`에서 빠졌고 현재 어디서도
  참조되지 않는 미사용 파일 — 정리하거나 실제 설정 화면으로 채울지 결정 필요.

## 백엔드 의존성

기능별로 호출하는 API는 [api.md](api.md) 참고. 이 앱은 mind-record 웹과 백엔드/DB를 공유하므로,
새 기능이 백엔드 스키마 변경을 필요로 하면 `mind-chart-backend`/`mind-record` 양쪽에 미치는 영향을
먼저 확인한다.
