# UI Style

색상 토큰 자체는 [design-system.md](design-system.md) 참고. 이 문서는 레이아웃/타이포/차트를 그리는 방식의
**목표 규칙**이다 (지금 코드가 아래 규칙을 전부 만족하는 건 아님 — 실제 구현 상태는 [features.md](features.md) 참고).

## 공통

- 화면 최상단은 `NavigationStack` + `.navigationBarTitleDisplayMode(.inline)`.
- 로딩 상태는 `ProgressView()`보다 `HeartLoader`(하트 박동 애니메이션)를 우선 사용 — 로딩이 오래 걸릴 수 있는
  화면(HealthKit/네트워크 동시 로딩 등)에서 통일된 느낌을 준다.
- 에러 메시지는 화면을 막지 않고, 해당 에러와 관련된 UI가 있는 자리(제목 위가 아니라 그 UI 바로 위/아래)에
  `.font(.footnote).foregroundStyle(.red)`로 노출한다 (AGENTS.md 규칙: 에러는 숨기지 않고 UI에 노출).
- 접근성: VoiceOver 등으로 화면의 모든 정보를 읽을 수 있게 한다.

## 차트 (Swift Charts)

### 성능
- 화면에 보이지 않는 구간까지 매번 다시 계산하지 않는다 — 스크롤/모드 전환 시마다 전체 데이터를 다시
  스캔하면 느려지므로, 범위 계산 같은 무거운 연산은 데이터·모드가 바뀔 때만 캐시해서 갱신한다.

### 여러 지표를 그릴 때
- **y축 단위가 다른 데이터는 겹쳐 그리지 않는다** — 예: HRV 값 vs 수면/운동 구간은 반드시 별도의 `Chart`
  인스턴스로 분리한다. 하나의 y축에 억지로 맞추면 가짜 눈금 값이 생긴다.
- **여러 Chart를 세로로 쌓아 하나처럼 보이게 할 때, x축 눈금 위치는 반드시 동일해야 한다.** Swift Charts의
  자동 눈금 계산에 맡기면 차트마다 다른 위치에 그려질 수 있으므로, 눈금 `Date` 배열을 직접 계산해서
  모든 차트의 `.chartXAxis`에 동일하게 적용한다.

### 크기
- 주 차트(HRV 라인/월별 막대)의 높이는 화면 전체 높이의 40%로 한다.
- 같은 x축을 공유하는 보조 차트(예: 수면/운동 Gantt 레인)는 주 차트 높이의 절반의 70%(= 주 차트의 35%)로 한다.

### 축 / 눈금
- 그리드 라인(`AxisGridLine`)은 옅게, 눈금 틱(`AxisTick`)은 그보다 진하게 — 그리드보다 축 자체가
  도드라져야 읽기 편하다. 그리드 라인은 최소한만 그린다(눈금마다 다 그리지 않고, 축을 읽는 데 필요한 개수만).
  - 예시: 그리드 `.gray.opacity(0.25)`, 틱 `.gray.opacity(0.85)`.
- x축은 눈금마다 그리는 세로 그리드(옅게, 그리드 색)와 플롯 하단을 가로지르는 축 기준선(진하게, 틱 색)을
  구분한다 — 세로 그리드를 진하게 하면 안 되고, 기준선만 진하게 한다.
- 같은 x축을 공유하는 차트를 세로로 여러 개 쌓을 때(라인 차트 + Gantt 레인), 차트 사이 레이아웃 여백은
  유지하되 세로 그리드는 그 여백을 관통해서 끊기지 않고 이어진 것처럼 보이게 한다 — 각 차트가 자기
  plotRect 안에서만 그리드를 그리면 차트 사이 간격에서 선이 끊겨 보인다.
- 축 라벨 폰트는 작게(예: 9pt), 단위(일/월/년 등)가 바뀌는 지점은 `.bold()`로 강조한다.
- y축 라벨은 차트 안에서 자리를 차지하지 않고 고정된 위치에 표시한다.
- y축은 0부터 시작하고 고정 간격(예: 50 단위)으로 그린다 — 데이터 min/max에 맞춰 축을 움직이면 값이
  실제보다 과장되어 보인다.
- x축 라벨은 서로 겹치지 않게 하고, 라벨 간 간격이 10px 이하로 겹칠 것 같으면 일부를 생략한다 — 생략하더라도
  같은 단위(예: 전부 "시:분" 또는 전부 "월-일")로 통일해서 표시한다.
- x축 라벨을 차트 안으로 표시해서 자리를 차지 하지 않도록 한다.
- x축 세로 그리드는 "정시"에만 찍는다 — 일별 모드는 자정(00시)에만, 시간별 모드는 분이 00일 때만.
  스크롤 위치(임의 시각) 그대로 일정 간격을 더하면 14:23처럼 어중간한 시각에 눈금이 생기므로,
  시작점을 가장 가까운 깨끗한 경계로 올림(ceiling)한 뒤 그 경계 단위로만 전진한다.

### 날짜 표기
기본 형식은 `yyyy-MM-dd HH:mm:ss`이며, 인접한 두 데이터 포인트 간 시간차에 따라 축약한다:
- 하루 미만 차이 → `HH:mm`
- 하루 이상 30일 미만 차이 → `MM-dd`
- 30일 이상 차이 → 월만(`M월`) 표기

### 스크롤 / 인터랙션
- 가로 스크롤은 Swift Charts 내장 `.chartScrollableAxes`가 아니라 `DragGesture` + `.chartOverlay`로
  직접 구현한다 — 내장 스크롤은 다중 Chart·커스텀 x축 조합에서 반응하지 않는 경우가 있었다. 스크롤은
  "지금 이후"로는 이동하지 못하게 클램프한다.
- 차트를 드래그/탭하면 그 x축 위치에 대응하는 y축 값을 함께 보여준다 (툴팁 형태).
- 하단에 범례를 두고, 범례 항목을 탭하면 해당 지표를 차트에서 보이기/숨기기 토글한다. 숨긴 항목은 범례에서
  투명도를 낮춰 "꺼져 있음" 상태를 표시한다.

## 인터랙션 (화면 전체)

- 간편 입력(홈 화면의 기분/커피 등)은 탭 한 번으로 끝나야 한다 — 폼을 열지 않고 바로 기록.
- 상세 입력(캘린더 날짜 탭)은 bottom sheet로 열어서 유형 선택 → 폼 순서로 진행.
